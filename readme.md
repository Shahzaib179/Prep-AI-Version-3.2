# Prep AI V3.2
## Adaptive AI Learning & Exam Preparation Platform

Prep AI V3.2 combines RAG, FAISS, Sentence Transformers, Gemini, CrewAI, web search and persistent SQLite learning memory.

## Main features

- Personalized Learning
- Database Learning
- PDF/DOCX/TXT/MD extraction
- Google Drive file/folder ingestion
- Metadata preservation
- Overlapping chunking
- Sentence Transformer embeddings
- FAISS semantic retrieval
- Keyword + semantic hybrid search
- Gemini source-grounded answers
- Adaptive MCQs
- Interactive quizzes
- Quiz performance tracking
- Topic-level mastery
- Weak-topic detection
- Smart revision scheduling
- Personalized study plans
- Exam mode
- AI Tutor
- CrewAI research agent
- DuckDuckGo search
- Retrieved-source display
- MCQ PDF export
- Streamlit settings for model selection and UI color

## Database FAISS artifacts

The app expects the pre-built database RAG artifacts:

```text
faiss_index/database.faiss
faiss_index/metadata.json
faiss_index/config.json
```

If your metadata was generated by the earlier ingestion pipeline, keep the same chunk text and fields:

- filename
- source
- file_type
- subject
- chapter
- topic
- page
- chunk_id
- chunk_index
- text

`embeddings.npy` is not required by the Streamlit app when `database.faiss` is already present.

## Streamlit Secrets

Create `.streamlit/secrets.toml` locally:

```toml
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
```

On Streamlit Community Cloud, open:

**App → Settings → Secrets**

and add the same key.

Never commit `secrets.toml`.

## Google Drive

The link must be accessible to the application, normally:

**Anyone with the link → Viewer**

Supported files:

- PDF
- DOCX
- TXT
- MD

The app uses the current `gdown` API and does not pass the obsolete `fuzzy=` argument that caused earlier Drive errors.

The downloaded filename is taken from the actual downloaded path, so source metadata uses the real Drive filename rather than a generic name.

## Adaptive learning logic

Student performance is stored in SQLite.

The system tracks:

```text
Subject
  ↓
Chapter
  ↓
Topic
  ↓
Question attempts
  ↓
Accuracy + difficulty + recency + mistakes
  ↓
Mastery score
  ↓
Adaptive difficulty
  ↓
Revision schedule
```

Mastery levels:

- 0–39: Very Weak
- 40–59: Weak
- 60–74: Developing
- 75–89: Strong
- 90–100: Mastered

## Important Streamlit Cloud note

SQLite storage on Streamlit Community Cloud is local to the running app instance and is not a production-grade shared database. For a multi-user production release, replace SQLite with a hosted database such as PostgreSQL/Supabase.

Likewise, pre-built FAISS files should be treated as application assets. Do not build the large database index inside the Streamlit request path.
